# DailyPromo0bot - Text to Speech Bot

🎙️ A powerful Telegram bot that converts text to speech in 12+ languages.

## Features

- 🗣️ Convert any text to natural-sounding speech
- 🌐 Support for 12+ languages
- ⚡ Fast and accurate
- 🎯 Easy to use
- 🆓 Completely free

## Commands

- `/start` - Welcome message
- `/help` - Help menu
- `/lang` - Change language
- `/about` - About the bot

## Deployment

This bot is deployed on Railway with GitHub integration.

### Environment Variables

- `TELEGRAM_BOT_TOKEN` - Your Telegram bot token from BotFather

## Technologies

- Python 3.11
- python-telegram-bot
- gTTS (Google Text-to-Speech)
- Docker
- Railway
